# Counsilio

Jurisdiction-aware legal drafting assistant. Choose your country, load matching official law sources, and draft papers with citations.

## Run locally

```bash
cd /Users/baqir/Projects/counsilio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Landing page with brand-first hero
- First-time onboarding: country → language → profile → disclaimer
- Assistant chat that cites country-specific official sources
- Documents studio (template entry points)
- Settings for profile, country, language, and active law pack
- Preferences stored in the browser (`localStorage`) for now

## Note

Counsilio is drafting and research assistance only — not a law firm and not legal advice.
